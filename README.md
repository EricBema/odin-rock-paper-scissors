# Rock Paper Scissors

A simple JavaScript exercise from The Odin Project Foundations course.

## Overview

This project is a basic implementation of the classic rock-paper-scissors game.

## Goals

- Practice JavaScript fundamentals
- Use functions, conditionals, and random logic
- Build a simple console-based game

## How to Play

1. Open the project in your browser or run it in a JavaScript environment.
2. The computer randomly picks rock, paper, or scissors.
3. You choose your move.
4. The game compares the choices and declares the winner.

## Notes

This is a small beginner-friendly exercise meant to reinforce core programming concepts in the Odin Project curriculum.
